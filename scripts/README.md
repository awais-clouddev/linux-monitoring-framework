# Monitoring Scripts

## Available Scripts

| Script | Purpose |
|---------|---------|
| cpu_check.sh | Monitor CPU usage |
| ram_check.sh | Monitor RAM usage |
| disk_check.sh | Monitor Disk usage |
| network_check.sh | Check network connectivity |
| service_check.sh | Verify Nginx service status |
| alert_check.sh | Detect abnormal conditions |
| update_dashboard.sh | Refresh dashboard data |
| generate_report.sh | Generate daily health report |
| run_all_checks.sh | Execute all monitoring scripts |

## Execution

Run all monitoring tasks:

```bash
bash scripts/run_all_checks.sh
```
