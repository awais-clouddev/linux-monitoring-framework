# Monitoring Dashboard

## Overview

The Monitoring Dashboard provides an up-to-date view of the Linux system after each scheduled or manual monitoring execution.

The dashboard displays the latest system health information generated by the monitoring framework and served through Nginx.

## Dashboard Information

The dashboard includes:

- CPU utilization
- RAM utilization
- Disk utilization
- Network connectivity status
- Nginx service status
- Active alerts
- Server information
- Latest monitoring timestamp

## Dashboard Update Process

The dashboard is automatically refreshed whenever the monitoring framework executes.

The workflow is:

```text
run_all_checks.sh
        ↓
update_dashboard.sh
        ↓
dashboard/status.txt
        ↓
Nginx
        ↓
Browser
```

## Dashboard Location

```text
dashboard/
├── index.html
└── status.txt
```

`index.html` provides the dashboard interface.

`status.txt` is automatically generated during every monitoring execution.
